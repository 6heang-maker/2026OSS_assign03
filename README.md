# Friend Manager

## Service Topic

친구 정보를 관리하는 Friend Manager를 만들었습니다.


## Data Fields

- Name : 친구 이름
- Relationship : 친구 관계
- Phone : 전화번호
- Email : 이메일
- Address : 주소
- Birthday : 생일


## List Page

index.html에는 다음 정보를 표시했습니다.

- Name
- Relationship
- Phone
- Email
- Birthday


## Validation


- 이름은 2글자 이상 입력
- 친구 관계 선택
- 전화번호 입력
- 이메일 형식 확인
- 주소 입력
- 생일 입력


## RWD

Bootstrap의 table-responsive와 CSS Media Query를 사용했습니다.

Table이 화면보다 큰 경우에는 가로 스크롤을 이용해서 볼 수 있도록 했습니다.


## Bootstrap

사용한 Bootstrap 기능입니다.

- container
- navbar
- card
- table
- table-responsive
- form-control
- form-select
- btn
- form-floating


## Problem 

모바일 화면에서 Table이 화면 밖으로 넘어가는 문제가 있었습니다.

table-responsive를 사용해서 모바일에서도 가로 스크롤로 Table을 확인할 수 있도록 했습니다.


## Reflection

이번 과제를 하면서 여러 HTML 페이지를 서로 연결하는 방법을 배웠습니다.

또 JavaScript로 입력값을 확인하는 방법과 Bootstrap, Media Query를 이용해서 모바일 화면에 맞게 페이지를 만드는 방법을 배웠습니다.
